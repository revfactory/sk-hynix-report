# Hynix Market Data Skill

SK하이닉스(000660.KS)의 시세·거래·수급·기술적 지표를 수집해 표준 보고서(`_workspace/01_market_data.md`)로 정리하는 워크플로우.

## 워크플로우

### Step 1: 기준 시점 확정
- 사용자가 기준일을 지정하지 않았으면 오늘 (KST) 기준
- 장중이면 실시간 데이터, 장 마감 후면 종가 기준임을 명시

### Step 2: 데이터 수집 — 출처별 우선순위

**1차 출처(국내):**
- KRX 정보데이터시스템(`data.krx.co.kr`)
- 네이버금융 종목페이지(`finance.naver.com/item/main.naver?code=000660`)
- 다음금융

**1차 출처(해외):**
- Investing.com (`investing.com/equities/sk-hynix-co-inc`)
- Yahoo Finance (`finance.yahoo.com/quote/000660.KS`)
- Google Finance

**WebSearch 키워드 예시:**
- "SK하이닉스 주가 종가" 
- "000660 시세"
- "SK Hynix stock price today"
- "SK하이닉스 외국인 지분율"
- "SK하이닉스 PER PBR"

### Step 3: 수집 항목 체크리스트

#### 3-1. 현재 시세 스냅샷
- [ ] 종가(또는 현재가) / 시가 / 고가 / 저가 / 거래량 / 거래대금
- [ ] 등락 (전일 대비 +/-, 등락률 %)
- [ ] 시가총액 (조원)
- [ ] 발행주식수, 우선주 발행 여부
- [ ] PER (TTM), PBR, EPS, BPS
- [ ] 배당수익률, 배당락일

#### 3-2. 가격 추이 (수익률)
- [ ] 1일, 1주, 1개월, 3개월, 6개월, YTD, 1년 수익률
- [ ] 52주 최고가 (날짜) / 52주 최저가 (날짜)
- [ ] 코스피 대비 상대수익률 (1개월/3개월/1년)

#### 3-3. 수급 (최근 5거래일·1개월·3개월 누적)
- [ ] 외국인 순매수, 외국인 지분율 변화
- [ ] 기관 순매수 (연기금, 금융투자, 투신, 보험, 사모펀드 등 세부 가능 시)
- [ ] 개인 순매수
- [ ] 공매도 잔고 비중, 공매도 거래 비중

#### 3-4. 기술적 지표
- [ ] 이동평균: 5/20/60/120/200일 — 현재가가 각 MA 대비 위치
- [ ] 정배열/역배열 판단
- [ ] RSI(14) — 과매수(70+)/과매도(30-)/중립
- [ ] MACD (12,26,9) — 시그널 위/아래, 히스토그램
- [ ] 스토캐스틱 (5,3,3) Slow
- [ ] 볼린저밴드 (20, 2σ) 위치
- [ ] 거래량 이상치 (20일 평균 대비 +50% 이상 발생일)

#### 3-5. 차트 패턴 & 추세
- 단기(1개월) / 중기(3~6개월) / 장기(1년+) 추세 방향
- 주요 지지선·저항선 (가격대 명시)
- 발견된 차트 패턴 (있는 경우만 — 헤드앤숄더, 컵앤핸들, 이중바닥/이중천장 등)

## 작업 원칙
- **데이터 불일치**: 출처 간 5% 이상 차이가 나면 양쪽 모두 기록하고 차이 원인 추정 (예: 거래소 기준 vs 야후 기준 차이)
- **결측은 명시**: 못 구한 항목은 "N/A (사유)"로 기록. 추정 금지
- **숫자 정확성**: 단위·소수점 둘째 자리·전일 대비 % 모두 정확히
- **장 상태 확인**: 거래 정지·관리종목·VI 발동 등 비정상 상태는 보고서 최상단에 강조

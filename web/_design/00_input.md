## 디자인 방향 (사용자 요구 기반)
- 다크 모드 우선 (금융 데이터 시각화 톤)
- 글래스모피즘 + 그라데이션 메시 + 네온 액센트
- 큰 타이포그래피 + 마이크로 인터랙션
- Hero 배경: WebGL shader gradient (Stripe·Linear 스타일) — 핵심 인터랙티브 요소

## 우선순위
1. 모던함과 시각적 임팩트 (1차)
2. 정보 정확성 (보고서 원본 1:1 매칭)
3. 인터랙티브 차트 (시세·HBM 점유율·시나리오 등 7종)
4. 배경/스크롤 애니메이션 (시그널 역할)
5. 반응형 (모바일 우선) + 접근성 (WCAG AA)
